# Northstar Digital Services GmbH — Financial Data Dictionary

This document details the data structures, dimension members, accounts, and file layouts generated by the synthetic data generator and ingested into the financial engine.

---

## 1. Dimensions Reference

### 1.1 Department Dimension (`departments.csv`)
* **Grain**: Department Entity
* **Hierarchy**: `COMPANY` is the consolidated top parent.

| Code | Department Name | Parent Code | Category |
|---|---|---|---|
| `COMPANY` | Northstar Digital Services GmbH | *None* | Consolidated Parent |
| `ENG` | Engineering | `COMPANY` | Operating Department |
| `SALES` | Sales | `COMPANY` | Operating Department |
| `MKT` | Marketing | `COMPANY` | Operating Department |
| `OPS` | Operations | `COMPANY` | Operating Department |
| `FIN` | Finance | `COMPANY` | Operating Department |

### 1.2 Account Dimension (`accounts.csv`)

### 1.3 Period Dimension
* **Time Span**: 2024-01 to 2026-12 (36 monthly periods).
* **Format**: ISO Period Key `YYYY-MM`.

---

## 2. Fact Files Structure (`actuals.csv`, `budgets.csv`, `forecasts.csv`)

| Field Name | Type | Permitted Values / Description | Example |
|---|---|---|---|
| `period` | String (7) | `YYYY-MM` format (2024-01 to 2026-12) | `2024-06` |
| `department` | String (10) | Active department code (`ENG`, `SALES`, etc.) | `ENG` |
| `account` | String (15) | Active account code (`REV`, `CLOUD`, etc.) | `CLOUD` |
| `scenario` | String (50) | Scenario name | `Actuals` |
| `version` | String (20) | Version tag (`v1`) | `v1` |
| `currency` | String (3) | ISO 4217 currency code | `EUR` |
| `amount` | Decimal (18,2) | Monetary amount with sign convention | `-45250.00` |
